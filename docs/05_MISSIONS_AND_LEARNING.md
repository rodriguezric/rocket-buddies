# Missions and Learning

## Goal
Players should learn because knowledge is useful in the adventure.

Avoid the pattern:
`fact → quiz → reward`

Prefer:
`problem → observation → discovery → knowledge becomes useful → success`

## Mission Anatomy
A mission defines:
- title,
- short briefing,
- destination,
- prerequisites,
- mode sequence,
- objectives,
- optional objectives,
- discoveries,
- rewards,
- completion conditions.

## Objective Types
Examples:
- reach location,
- collect resource,
- rescue entity,
- scan object,
- discover landmark,
- solve environmental problem,
- survive/complete flight,
- resolve Merf encounter,
- return safely.

## Example: Olympus Meep
Briefing: a strange Meep signal was detected near an enormous Martian mountain.

During exploration, the player learns it is Olympus Mons and uses scanner/topography clues to locate the Meep.

The knowledge is attached to accomplishing something rather than answering a detached question.

## Example: No Landing on Jupiter
A mission asks the player to investigate Jupiter. Navigation/ship systems explain that Jupiter has no solid surface appropriate for a normal landing. The player instead selects an orbital/moon destination.

The fact changes the player's plan.

## Journal
Journal categories:
- Sun,
- planets,
- dwarf planets,
- moons,
- landmarks,
- phenomena,
- human exploration.

Each entry should contain:
- illustration,
- one-sentence child-friendly summary,
- several optional facts,
- where it was discovered.

Meeps/Merfs/Cheese belong in separate whimsical collections so fictional material is visually distinguishable from astronomy reference material.

## Accuracy Rule
Educational content must distinguish:
- established scientific information,
- simplified models,
- fictional Rocket Buddies lore.

Do not imply Moon Cheese, Meeps or Merfs are scientific facts.

## Hints
Hints should escalate:
1. environmental cue,
2. Buddy observation,
3. scanner clue,
4. explicit guidance.

No penalty for requesting hints.
